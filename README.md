
# Industrial By-Product B2B Matchmaking Engine

## Project Description
This project connects industries producing reusable by-products
with industries that need those materials.

## Technologies
- Python
- Streamlit
- Pandas
- CSV datasets

## Features
- Supplier and buyer data management
- Automatic material matching
- Quantity and purity checking
- Interactive dashboard
- CSV download of matching results

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Dataset
- data/suppliers.csv
- data/buyers.csv
